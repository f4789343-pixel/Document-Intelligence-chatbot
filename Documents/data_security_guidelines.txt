DATA SECURITY GUIDELINES
Northstar Solutions - Employee Reference

1. Data classification
Public data may be shared externally. Internal data is intended for employees and approved contractors. Confidential data includes customer records, financial information, and non-public business plans. Restricted data includes credentials, private keys, and highly sensitive personal information.

2. Access control
Employees should access only the information required for their job responsibilities. Access permissions must be reviewed when an employee changes roles and removed when employment ends.

3. Sharing files
Use company-approved storage and collaboration tools. Verify recipient addresses before sharing confidential files. Do not create public links for confidential or restricted information.

4. Credentials
Never share passwords, API keys, recovery codes, or private keys in chat messages, source-code repositories, or support tickets. Store application secrets in an approved secrets manager or protected environment configuration.

5. Security incidents
Report suspected phishing, unauthorized access, lost devices, or accidental data disclosure to the Security Team immediately. Preserve relevant evidence and do not attempt to conceal or independently investigate an incident.

6. Retention
Keep business records according to the company's retention schedule. Delete temporary local copies when they are no longer needed and when permitted by the applicable retention rules.

7. Questions
Contact security@northstarsolutions.example for guidance.
